# Security

Please do not publish secrets, API keys, tokens, credentials, database files, or other private information in issues or pull requests.

For a suspected security issue, avoid posting exploit details publicly. Contact the repository owner privately with a clear description of the affected component, reproduction steps, and impact.

RBGraph treats diagram descriptions and commands as untrusted input. New code should preserve validation and escaping boundaries when moving data between the API, SVG, HTML, and browser layers.
